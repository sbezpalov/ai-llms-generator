# Replacing an SEO-plugin llms.txt dump (WordPress / Rank Math)

`example-llms.txt` in this repo is the **curated golden** for
[blog.bezpalov.com](https://blog.bezpalov.com/). A live `/llms.txt` that starts
with `Generated by Rank Math SEO` (or lists dozens of archive posts) is a
**dump**, not an AIO layer-2 map.

## Goal

Serve the curated file at `https://<host>/llms.txt` instead of the plugin dump.

## WordPress + Rank Math (typical)

1. In Rank Math, disable automatic `llms.txt` generation / LLM sitemap export
   (wording varies by Rank Math version: look for llms.txt / LLM / AI features).
2. Upload or create a static `llms.txt` in the **web root** (same level as
   `robots.txt`), using the contents of this repo’s `example-llms.txt` (or your
   own curated draft from `/generate-llms-txt`).
3. Confirm in a private window: `https://your-site.com/llms.txt` shows the
   curated H1/blockquote/`## Optional` shape — **not** “Generated by Rank Math”.
4. Keep `sitemap.xml` for full crawl inventory; do not paste the sitemap into
   `llms.txt`.

## Drop-in from this repository

```bash
# After cloning ai-llms-generator:
cp example-llms.txt /path/to/wordpress-root/llms.txt
```

Or paste `example-llms.txt` via SFTP / hosting file manager into the document
root.

## Verify

- [ ] File begins with `# Site Name` (not a plugin preamble)
- [ ] Size ≲ 8 KB; sections ≤ 12 links each
- [ ] About / policy links included when those pages exist
- [ ] `Last updated` is today’s date after each structural edit
